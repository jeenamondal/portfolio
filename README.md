# Jeena Mondal — Portfolio

> Personal portfolio for Jeena Mondal, 2nd year Computer Science & Engineering undergraduate at Lovely Professional University (LPU).

## Highlights
- **Design Aesthetic**: Minimalist, clean grid layout inspired by [bidyut.cc](https://bidyut.cc).
- **Featured Project**: [Brain-Controlled Buggy](https://github.com/jeenamondal/brain_controlled_buggy) — Robot buggy driven by biosignals (EEG + EMG) via BioAmp EXG Pill.
- **Certificates**: Interactive modal preview and downloadable PDFs for Infosys Springboard and Saylor Academy certifications.
- **Tech Stack**: Python, C, C++, JavaScript, TypeScript, React, Next.js, Tailwind CSS, Node.js, Git, GitHub, PostgreSQL, AWS, Docker, Vercel, and AI tooling.
- **Zero-Build Deployment**: Pure static assets compatible with instant hosting on Vercel and GitHub Pages.

## Deployment
This project is static HTML/CSS and deploys automatically on Vercel without build steps.
